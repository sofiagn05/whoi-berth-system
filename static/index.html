Dock schedule grid

The same berth × day grid staff used to check by eye for double-bookings — except this one flags conflicts automatically. Click an empty cell to start a booking there; click an occupied cell to inspect or delete it.

Vessel dimensions

The imported schedule has vessel names but not LOA/beam/draft, so most fit checks currently show as "unknown" rather than pass/fail. Upload a CSV (columns: name, loa_ft, beam_ft, draft_ft, vessel_type) to fill in dimensions for vessels that already exist — this won't create new vessels, only update matching names.

Audit: existing double-bookings & fit violations

Runs the double-booking and dimension-fit checks across every booking in the system — the automated replacement for eyeballing the grid.

Resolve all conflicts at once

Computes a single reassignment plan for every conflict in the system together (optimal weighted interval scheduling per berth, then best-fit placement for whatever's displaced) instead of fixing one booking at a time.

New booking

If berths run short, the conflict resolver protects higher-priority reservations first, regardless of how long a lower-priority one is.
